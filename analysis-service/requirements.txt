# Versions are pinned so "it works on my machine" also works on your
# teammates' machines. numpy is capped below 2.0 because faster-whisper's

# These are grouped to match BUILD_ORDER.md. The code imports librosa/av/
# faster-whisper/rapidfuzz lazily (inside the functions that use them), so
# you can genuinely install just the "Step 1" group, get the skeleton
# running end-to-end with STUB_MODE=true, and install the rest later when
# you reach Step 3 - you don't have to wait ~150MB of model download and a
# handful of heavier native packages before you see anything working.
